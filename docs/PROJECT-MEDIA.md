Captured from the local web-dist build. Registers and disassembly are actual runtime values. They document one coherent symptom/booking/payment walkthrough. The persistent demo notice is part of the real app. No government identity, camera, booking, payment or SMS service was contacted.
- CardioSense: instrument.webp shows the actual original-cohort input and score; contributions.webp shows signed Logistic Regression terms for the same app. No fabricated ECG is used.
- Knee MRI: reading-room.webp shows actual study 02 / 101708986158, coronal fluid-sensitive series, original frame and held-out outputs. The viewer contains one preview frame per series, not a browsable slice stack.

Raw captures with .png filenames contain native browser image bytes (some are JPEG despite the extension). Sharp detects the actual format. Public rendering uses optimized WebP. Run node scripts/prepare-captures.mjs to reproduce conversions and the recorded CHIP-8 enclosure crops.
